# 🚀 MetaForge Pro 超级简化入口

> **30秒上手，一个指令启动，万能指令救援**

## ⚡ 立即开始

### 启动指令

在 Cursor 中输入以下任意一个指令即可开始：

```
🚀 启动MetaForge：我想开发一个 [你的项目描述]
```

**示例**:
- `🚀 启动MetaForge：我想开发一个待办事项应用`
- `🚀 启动MetaForge：我想开发一个电商网站`
- `🚀 启动MetaForge：我想开发一个企业CRM系统`

### 万能救命指令

如果你在任何时候感到迷路、困惑或不知道下一步做什么：

```
❓ 我迷路了，请告诉我当前状态和下一步该做什么
```

## 🎯 你只需要记住的 3 件事

### 1. 你是产品经理，AI 是开发团队
- **你负责**：表达需求、确认方案、提供反馈
- **AI负责**：技术实现、代码编写、质量保证

### 2. 一切按 6 个阶段进行
```
概念定义 → 需求规划 → 架构设计 → 开发实施 → 质量测试 → 部署运维
```
每个阶段完成后，AI 会请你确认再进入下一阶段。

### 3. 任何时候都可以寻求帮助
- `❓ 我迷路了` — 查看当前状态
- `⏸️ 暂停一切` — 暂停工作流程
- `📊 项目进度` — 查看整体进展

## 💡 常见问题

### Q: 我完全不懂编程，能用吗？
**A**: 完全可以！你只需要用自然语言表达你的想法，AI 会处理所有技术细节。

### Q: 如果 AI 的方案我不满意怎么办？
**A**: 直接说出你的想法和期望，AI 会根据你的反馈调整方案。

### Q: 一个项目需要多长时间？
**A**: 取决于项目复杂度：
- 简单应用（博客、待办）: 3-7 天
- 中型应用（电商、管理系统）: 4-8 周
- 复杂应用（SaaS、平台）: 8-16 周

### Q: 可以中途修改需求吗？
**A**: 可以，但建议在每个阶段结束时提出修改，这样对项目影响最小。
